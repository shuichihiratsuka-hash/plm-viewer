# plm-viewer

`plm-gas`（社内の PLM）から開く **3D / 図面のビューア**。GitHub Pages で配信します。

**→ https://shuichihiratsuka-hash.github.io/plm-viewer/**

## なぜ plm-gas の外に置くのか

`plm-gas` は Apps Script のウェブアプリで、画面が `googleusercontent.com` の
iframe の中で動きます。そのため：

- `drive.google.com` への `<img>` / `fetch` は**別サイトへの要求**になり、
  ブラウザが Drive の Cookie を送らないので**非公開ファイルは 403** になる
  （2026-08-22 に iOS Safari で実測）
- 回避のためサーバ（GAS）で中継すると、`google.script.run` の
  **ペイロード上限**に当たる。⚠️ 実データは**治具1点で 10.5MB**、組立はさらに大きい

**Drive API は CORS に対応している**ので、ページから直接 `files.get?alt=media` を
叩ければ中継が要らず、上限も消えます。それには plm-gas とは別の
**普通のオリジン**が必要で、その置き場がここです。

## できること（★2026-08-23 に両方とも実測できた）

| 入口 | どう使うか | 実測（iPhone・`めっき治具_L0.stp` **10.5MB**）|
|---|---|---|
| **ファイルを選ぶ** | 端末のファイルを選んで描く | WASM 0.3秒 ＋ 変換 5.4秒 ＝ **5.7秒**（三角形 140,046 / 頂点 113,558）|
| **`#id=<DriveのファイルID>`** | Drive から**直接読んで**描く | ダウンロード 1.4秒 ＋ 変換 5.6秒 ＝ **7.1秒** |

`plm-gas` からは後者で開きます（`coreOpen3d` が `#id=` を付けた URL を別窓で開く）。
初回だけ Google の許可を1回聞かれます（`drive.readonly`）。

⚠️ **組立はまだ測っていません。** 上は治具1点の数字で、大きさが1桁違うと
別の壁に当たり得ます（測ったらここに追記してください）。

⚠️ 読めるのは **STEP / IGES** だけです（`.stp` `.step` `.igs` `.iges`）。
**glTF / GLB は読みません。**

## セキュリティの境界

- ページは**誰でも開けます**が、**図面データはページに含まれません**
- 読めるのは「開いた人が **Drive でそのファイルを開ける権限**を持つもの」だけ。
  ⇒ 境界は Google 側に残ります
- ⚠️ ただし**ファイルIDは URL に乗ります**（`#` の後ろなのでサーバには送られませんが、
  リンクを渡せばその人の権限で開けます）

## OAuth の設定（★一度きり。作り直すときの手順）

`config.js` の `CLIENT_ID` に入れる値を作る手順です。
**クライアント シークレットは使いません**（ブラウザだけの OAuth なので不要。
クライアント ID は公開してよい値で、実際にこのリポジトリに入っています）。

| 手順 | どこで |
|---|---|
| ① Google Cloud のプロジェクトを開く（会社のアカウントで）| https://console.cloud.google.com |
| ② **Google Drive API** を有効にする | API とサービス → ライブラリ |
| ③ **Google Auth Platform**（旧「OAuth 同意画面」）で**対象**を **内部** にする | https://console.cloud.google.com/auth/audience |
| ④ **スコープ**に `.../auth/drive.readonly` を足す | https://console.cloud.google.com/auth/scopes |
| ⑤ **クライアント**を作る（種類＝**ウェブ アプリケーション**）| https://console.cloud.google.com/auth/clients |
| ⑥ **承認済みの JavaScript 生成元**に `https://shuichihiratsuka-hash.github.io` を入れる | 同じ画面 |
| ⑦ 出てきた**クライアント ID** を `config.js` に貼る | このリポジトリ |

- ⚠️ **内部（Internal）**にすると Google の審査が要りません（社内の人だけが使えます）
- ⚠️ **リダイレクト URI は要りません**（トークンクライアント方式なので使いません）
- ⚠️ 生成元は**オリジンまで**（`https://…github.io`）。**パスを付けると弾かれます**
- ⚠️ 新しいコンソールでは「OAuth 同意画面」という名前が**「Google Auth Platform」**、
  「内部 / 外部」が**「対象」**に変わっています（見出しを探すときの手掛かり）

## 行き止まりを作らない（`driveOut`）

読めない形式・権限なし・404・ダウンロード失敗のときは、**「Drive で開く」を出します**。

⚠️ **`plm-gas` から「3D」を押した人にとって、ここが最後の窓**です。
文言だけ出して終わると Drive を自分で探し直すことになります。

⚠️ **「回せない」は失敗ではありません。** 社内の出図には **SLDPRT** も貼るので、
読めない形式は普通に来ます（読めるのは STEP / IGES だけ）。
赤いエラーで終わらせず、次の行き先を出します。

## 踏んだこと

### 🔴 GIS の読み込みを「待つ」（1回目は開けて2回目でエラーになった）

`#id=` で開いたとき、**GIS（`accounts.google.com/gsi/client`）の読み込みを待たずに
在るかどうかを1回見て諦めていた**。あれは `async defer` なので module の実行より
後に来ることがある。

- **1回目**：three.js を jsDelivr から落とす時間で GIS が間に合う → 開ける
- **2回目**：キャッシュで全部速いので **module が GIS を追い越す** → 「Google の
  ログインを読み込めていません」

⚠️ **スマホ固有ではない。** キャッシュの有無で決まる競合。
→ `gisWait()` で**在るまで待つ**（15秒で諦める）。0.4秒を超えたら
「読み込んでいます…」と出す（黙って待たない）。

### 🔴 リロードで毎回ログインを求められるのは意図どおり（ポップアップの確認は違う）

実機で「Safari でリロードすると毎回ログインを求められる」と指摘された。
**2つの別の話が同時に見えている。**

| 見えるもの | なぜ | どうしたか |
|---|---|---|
| **リロードでログインを求められる** | トークンを**変数にしか持っていない**（保存しない）| ★**意図どおり。変えない**（下記）|
| **「このサイトではポップアップウインドウが開きます」** | `#id=` で開いた直後に**自動で**トークンを要求していて、**タップと紐づいていない**。Safari はそれを止めて聞く | ✅ **直した**（下記）|
| **毎回アカウント選択・同意が出る** | `prompt` を指定していなかった | ✅ `prompt: ''` を付けた |

**① トークンは保存しない。**`sessionStorage` に置けばリロードをまたげるが、
**アクセストークンを web storage に置く**ことになる。これは図面が読める鍵なので置かない。
⚠️ 有効期限は約1時間で、切れたときの再取得も同じ経路を通る。

**② `prompt: ''`（出す必要が無ければ画面を出さない）。**
一度許可した人には**アカウント選択も同意も出ない**。これが無いと**リロードのたびに
選択画面**が出る。

**③ 🔴 読み込みは「タップから」始める。自動で読み込まない。**

`requestAccessToken()` は **必ずポップアップを開く**。`prompt: ''` はポップアップ
**の中**の同意画面を省くだけで、**窓そのものは開く**。
★つまり **「黙って試す」経路は存在しない。**

Safari は**ユーザー操作と紐づかない**ポップアップを止めて聞くので、
`#id=` で開いた直後（＝タップが無い）に自動で要求すると、**毎回あの確認が出る**。

⇒ `#id=` のときは `tapToLoad()` で**タップを待つ**。押した先は、既に許可済みなら
画面が出ずに読み込みが始まる。

⚠️ **自動要求に戻さないこと。** 一見親切だが、確認が毎回出る方が煩わしい。
⚠️ 「押してください」だけ書かない。**押すと何が起きるか**を書く。

## 🔴 ページごと飛んで戻る（ポップアップを使わない。これが本線）

`#id=` で開いたときは **Google へページごと飛んで戻る**。ポップアップもタップも要らない。

| 経路 | 何が起きるか |
|---|---|
| 許可済み・ログイン中 | **画面が出ずに戻ってくる**（`prompt=none`）→ そのまま読み込み |
| 未許可・未ログイン | 「Google の画面へ進む」を出す → 押すと**ページごと**飛ぶ（1回だけ）|
| トークン切れ（約1時間）| **黙って取り直す**（`prompt=none` でもう一度飛ぶ。1回だけ）|
| `REDIRECT_URI` が空 | ポップアップ方式（1回タップ）に落ちる |

### 設定（★これをやらないと Google のエラー画面が出る）

`config.js` の `REDIRECT_URI` と**同じ文字列**を Google Cloud に登録する。

| 欄 | 入れるもの |
|---|---|
| 承認済みの **JavaScript 生成元** | `https://shuichihiratsuka-hash.github.io`（★ドメインだけ）|
| 承認済みの **リダイレクト URI** | `https://shuichihiratsuka-hash.github.io/plm-viewer/`（★末尾の `/` まで）|

⚠️ **別の欄。両方要る。** ⚠️ 1文字でも違うと `redirect_uri_mismatch` になり、
**Google のエラー画面**が出る（こちらには戻ってこないので画面で説明できない）。

### 実装の決めごと

- ⚠️ **`state` に id と hint を入れて持ち回る。** 飛んでいる間 `#id=` は消える。
  ★`state` は**エラーのときも返ってくる**ので、「もう試した」の印（`r`）も入れて
  **無限に飛ばない**ようにしている
- ⚠️ **戻ってきたらトークンを URL から消す**（`history.replaceState`）。履歴・共有に残さない。
  `#id=` は残す（そのままリロードできる）
- ⚠️ **`prompt=none` が通らないのは失敗ではない。** 同意かログインが要るだけなので、
  「進む道」を出す。**一度許可すれば以後は画面が出ない**と書く

### 🔴 枠の中のボタンが押せなかった（`pointer-events`）

`#ph`（真ん中の枠）は `position:absolute; inset:0` でキャンバスに重なるので、
**モデルを回すドラッグを吸わないよう `pointer-events:none`** を付けている。

⚠️ **これは中のボタンにも効く。** 戻していなかったので、
**「Drive から読み込む」「もう一度」「Drive で開く」の3つが全部押せなかった**
（押すと素通りして裏のキャンバスに行く／2026-08-23 に実機で踏んだ）。

```css
#ph{ … pointer-events:none }
#ph button,#ph a{ pointer-events:auto }   /* ★これを忘れない */
```

★**見えていて押せないものは「壊れている」と読まれる。**
枠の中に操作を置くときは必ず `auto` を戻す。

### 「もう一度」を出す

ログインまわりの失敗（同意を閉じた・読み込みが遅れた）は**押し直せば通る**ことが多い。
`retryOut()` でその場にボタンを出す。⚠️ Drive へ逃がす `driveOut()` とは別物
（あちらは「このページでは開けない」、こちらは「やり直せば開ける」）。

### ボタンは残す（`STEP を選ぶ` / `Drive から`）

`#id=` で開いたときは本命が自動で走るので **`STEP を選ぶ` を主役から降ろす**（青くしない）が、
**消さない**。ビューアとして単体で使いたい人の入口として残す。

### 🔴 `<input type="file">` に `accept` を付けない

`accept=".stp,.step,…"` を付けていたら、iPhone の**ファイル選択で全部グレーアウトして
選べなかった**（2026-08-23 に実機で発生。OneDrive に落とした `.stp` が選べない）。

iOS は `accept` を **UTI（ファイル種別の識別子）の一覧に翻訳**するが、
`.stp` / `.step` には登録された UTI が無く、`application/step` も認識されない。
結果として**許可リストが空同然になる**。

→ **`accept` を付けず、種別の判定は JS（`kindOf`）でやる。**
⚠️ 読めない拡張子を渡されたら**そう言う**（変換に投げて意味不明な失敗にしない）。
